# 六路相机扬尘标注

启动：
```bash
bash ~/Downloads/start_dust_annotation.sh
```
浏览器会打开 http://127.0.0.1:8765/ 。终端保持运行；如未自动打开，手动复制地址到浏览器。这个工具需要启动脚本，不能直接打开旧的 index.html。

- 顶部选择 scene_0 / scene_1 / scene_2。
- 同时显示同一时间戳的 cam0～cam5。缺帧位置灰显，不伪造图片或记录。
- 第一个新帧的各相机默认无尘。点击图片，在弹窗选择 1 轻度（黄色）、2 中度（橙色）、3 重度（红色）。选择即确认并保存。
- 选择 0 无尘可取消扬尘状态，边框恢复无色。弹窗支持键盘 0/1/2/3，Esc 取消。
- 点击下一帧或键盘右箭头，六路同步更新。手动选择某相机的 0/1/2/3 后，该相机的等级随下一帧持续保存，直到再次修改；即使下一帧已有旧标注，也按本次新选择覆盖。其他未重新选择的相机保留旧帧记录，新帧仍按原规则继承。
- 左箭头/上一帧仅浏览时不改旧记录，并结束当前向前覆盖状态。回退后重新点击图片选择等级（即使选择相同等级），会重新启动该相机的向前覆盖。只改动每次下一帧实际走到的位置，不批量改写尚未走到的未来帧。
- 切换 scene 不跨场景继承；每个 scene 独立保存进度。
- 请区分“浏览后未操作（采用默认/继承）”与“尚未浏览”。未浏览帧不会当作已确认无尘导出。

保存目录默认为 ~/Downloads/dust_annotations：
- scene_0.json 等：每次操作原子保存，含当前位置、逐帧相机号、图片 name、level、手动/继承来源。
- 点击导出 CSV，生成 annotations.csv（所有已访问图片，含无尘）和 dust_only.csv（仅1/2/3级）。导出是保存到上述目录，不是浏览器下载。
- Ctrl+C 正常停止服务器时也会导出 CSV。异常退出或关闭网页后，JSON 已保存；重新启动恢复进度，可再导出。
- JSON 是断点恢复的主文件，勿手工删除或只保留 CSV。
- 原始图像和已有配对复核文件均不修改。建议只在一个浏览器标签页标注。

自定义路径或端口：
```bash
bash ~/Downloads/start_dust_annotation.sh --root /home/ivan/project/IJRR --output ~/Downloads/dust_annotations --port 8766
```
Python 3 标准库即可启动；Pillow 可加速生成缩略图。启动脚本优先使用本机带 Pillow 的 Anaconda Python。页面看的是缩略图，原图保持不变。

已验证：独立相机继承、0清除、返回不覆盖、断点恢复、跨scene隔离、缺帧、CSV导出，以及本地HTTP加载六路真实图像。未在此环境中自动化操作图形浏览器。

回退修正示例：回到第100帧，cam0选择2；随后下一帧到101/102时均保存cam0=2。到103改为0，则之后下一帧持续保存0。向前覆盖状态写入JSON，刷新或重启可恢复；再次点击上一帧则结束本轮覆盖，避免后方状态污染前方帧。更新脚本后需Ctrl+C停止旧服务并重新运行启动脚本，再刷新浏览器。
